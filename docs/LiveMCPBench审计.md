- 离线 `plan`：9 个生成组、32 个评分组；855 次任务生成、3040 次评分、约 665 次自动关键点提取。
- 覆盖旧配置迁移、保留已有设置、错误模型身份拒绝、子进程组超时、中断/失败不静默重跑、部分复现永不标为完整论文复现。
- 发布前仅暂存源码、模板、测试与文档；使用常见凭证模式检查和 Git 忽略规则检查，不包含真实密钥、权重、原始轨迹或运行日志。这是定向检查，不是完整的第三方密钥扫描认证。

## 尚未验证或实现

1. **实际可运行性**：未连接用户远程容器，GPU 型号/显存、CUDA/vLLM、依赖安装、70 个在线 MCP 服务及各 API 权限均未实测。
2. **模型与路由**：保留模型仅有公开端点查询证据。GPT-5 参数兼容性、Gemini 账号权限、量化版本和实际提供方需验证；当前没有自动锁定 OpenRouter 路由。正式实验前需解决或明确记录差异。
3. **本地生成模型**：尚未自动下载/启动 Qwen3-32B-AWQ，也未实现独立小样本诊断或只下载数据子命令。当前本地只启动 Qwen3 Embedding。
4. **检索一致性**：固定原索引，只对 70 个 Server 描述重算向量进行校准；不能据此保证所有查询、摘要与工具向量的预处理绝对等价。
5. **工具环境与隔离**：工具包可能使用可变版本或依赖额外服务；list_tools/schema 检查不代表工具执行一定成功。任务可运行文件与命令操作，必须使用专用容器；附件副本与进程组清理不构成完整容器沙箱，也未验证所有 MCP 子进程的真实退出行为。
6. **模型集合变化**：排除两款 Claude 4 和原版 Qwen3-235B，移除依赖实验；统计只能代表保留集合的部分复现。公开 Sonnet 轨迹复评不是本次新生成成绩。
7. **成本与人工验收**：记录 token，不自动给出已核验的总费用；价格、案例分析、来源差异和人工证据仍需复核。

上述未完成项应保留在审阅说明中，不通过删除任务、填假数据或把服务异常算成普通失败来隐藏。
